# WEB-004 — First-Admin and Password-Reset Flows

**Status:** COMPLETE
**Owner:** Codex
**Workstream:** Web  
**Depends on:** WEB-003

## Scope

Implement self-hosted account bootstrap/reset behavior.

- First admin.
- One-time temp password.
- Forced change.
- Explicit CLI/container reset.
- Admin user creation.

## Out of scope

- Unrelated workstreams.
- Product feature implementation beyond this task.
- Architecture changes not required by this task.

## Acceptance criteria

- [x] Normal restart does not reset account.
- [x] Reset is explicit.

## Validation

Run all checks relevant to the packages/services introduced or changed by this task.

## Notes / blockers

Explicit administrator commands create a first account once, issue a temporary password with forced change, and revoke sessions during a deliberate reset. Normal web startup never creates or resets an account.
