# WEB-002 — Localization and Theme Integration

**Status:** IN PROGRESS
**Owner:** Codex
**Workstream:** Web  
**Depends on:** WEB-001, UI-002

## Scope

Integrate i18n and theming into the web application.

- Typed locale catalogs with English regional defaults.
- Runtime locale context and browser preference persistence.
- Locale-aware text, plural, and format helpers.
- Theme persistence.

## Out of scope

- Unrelated workstreams.
- Product feature implementation beyond this task.
- Architecture changes not required by this task.

## Acceptance criteria

- [x] Visible shell text reads from the active locale context.
- [x] Locale catalogs must satisfy the English catalog keys at compile time.
- [x] Browser and persisted locale preferences resolve to a supported locale and update document language.
- [x] Dates, numbers, relative time, and plural forms use the active locale.
- [x] Light/dark work.

## Validation

Run all checks relevant to the packages/services introduced or changed by this task.

## Notes / blockers

The runtime now uses typed `en-US` and `en-GB` catalogs with an extensible registry, persisted browser preference resolution, locale-aware `Intl` formatters, plural forms, and a document-language synchronization test. All application screens read translations through `useI18n`; direct English catalog imports are limited to tests.
