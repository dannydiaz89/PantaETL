# WEB-009 — Source File Upload

**Status:** COMPLETE
**Owner:** Claude
**Workstream:** Web  
**Depends on:** WEB-003, WEB-006, DB-004, GC-002, CONTRACT-009

## Scope

Allow an operator to supply a file to a file-backed Source from the browser
instead of placing it into internal storage by hand.

- Authenticated upload endpoint writing beneath the configured import directory.
- Staged-upload metadata carrying an explicit owner and expiry.
- Upload control in the Source configuration step that fills in the source path.
- Per-field help text explaining what a source path is.
- Release of staged state once a saved pipeline depends on the file.

## Out of scope

- Unrelated workstreams.
- Product feature implementation beyond this task.
- Architecture changes not required by this task.
- S3-compatible upload targets.
- Browsing or listing the contents of internal storage.

## Acceptance criteria

- [x] Only an authenticated operator may upload.
- [x] Uploads are size-capped and restricted to permitted file types.
- [x] A stored location can never escape the configured import root.
- [x] Every staged upload records a durable owner and expiry so retention can reclaim it.
- [x] A file a saved pipeline reads is no longer a retention candidate.
- [x] Manual path entry keeps working for files already present in internal storage.
- [x] Design system only.
- [x] All text localized.

## Notes / blockers

Retention already models staged uploads and the garbage collector already reclaims
them; only the write path and the operator-facing control were missing. Uploads land
in the same import root the Source components resolve against, so an uploaded file and
a hand-placed file are indistinguishable to execution.

Because the collector selects staged uploads by expiry alone, a file left staged after
a pipeline began reading it would have been deleted while still in use. Saving a
pipeline that names an uploaded path now releases the staged row, transferring
responsibility for the file to the pipeline. Files placed into internal storage by
other means were never staged and are unaffected.
