## Validation

Run all checks relevant to the packages/services introduced or changed by this task.

## Notes / blockers

Development configuration now uses an ignored root `.env` file with a committed
`.env.example`. Direct Vite development reads root server-side environment values;
Compose consumes the same values and derives its internal PostgreSQL connection
hostname. No authentication secret or database credential is embedded in Compose.

Validated with `docker compose --env-file .env.example config --quiet`,
`pnpm --filter web check`, ESLint, and `git diff --check`.
